# 🔍 Simple Python Port Scanner

A lightweight and fast Python script developed to check for open ports on servers and networks. Created as part of my studies in cybersecurity and automation.

## 🚀 Features
* Fast TCP port scanning.
* Connection error handling.
* Simple command-line interface (CLI).
